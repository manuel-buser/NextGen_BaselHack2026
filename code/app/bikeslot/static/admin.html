User page

No rack in the racks file is read from the vision service.

1 · Live camera

The picture as the camera sends it, people blurred on the camera. It is lined up with a saved picture of the rack, so the 19 hooks always sit in the same place.

2 · Model 1: hook classifier

A small neural network (MobileNetV3, trained on this camera) looks at each hook on its own and gives the chance that a bike hangs there. Red: bike, green: free, grey: unsure. On its own it also lights up the hooks next to a bike.

3 · Model 2: bike finder and final answer

Grounding DINO counts the bikes. A lit hook is freed only when it can be nothing but the overlap of a bike found next to it; when unsure, a hook stays taken. This is what the app shows.
